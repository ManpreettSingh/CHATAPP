# SYSTEM SPECIFICATION

## 1. Hardware Specifications

### Development Environment:
- **Processor:** Intel Core i5/i7 or AMD Ryzen 5/7 (or equivalent).
- **RAM:** 8 GB (minimum); 16 GB (recommended for smoother development).
- **Storage:** 256 GB SSD (minimum); 512 GB SSD or higher (recommended).
- **Graphics:** Integrated GPU (sufficient for web development).
- **Display:** Full HD (1920x1080) resolution monitor.

## 2. Software Specifications

### Development Tools:
- **Operating System:** Windows 10/11, macOS, or Linux.
- **IDE/Editor:** Visual Studio Code (preferred) or any text editor.
- **Version Control:** Git with GitHub for code management.
- **Package Manager:** npm (Node Package Manager).

### Frameworks and Libraries:

**Frontend:**
- React.js (v19.1.1) with TailwindCSS (v4.1.14) and DaisyUI (v5.3.7) for styling.
- Vite (v7.1.7) for build tool and development server.
- Zustand (v5.0.8) for state management.
- Socket.IO Client (v4.8.1) for real-time WebSocket communication.
- Axios (v1.12.2) for HTTP requests and React Router DOM (v7.9.4) for navigation.
- React Hot Toast (v2.6.0) for notifications and Lucide React for icons.

**Backend:**
- Node.js (v16+) with Express.js (v5.1.0) for RESTful API development.
- Socket.IO (v4.8.1) for WebSocket server implementation.
- Mongoose (v8.19.1) for MongoDB object modeling.
- JWT (v9.0.2) for authentication and bcryptjs (v3.0.2) for password hashing.
- Cloudinary (v2.7.0) for cloud-based image storage and delivery.
- CORS (v2.8.5), Cookie Parser (v1.4.7), and dotenv (v17.2.3) for middleware.
- Nodemon (v3.1.10) for automatic server restart during development.

**Database:**
- MongoDB (v5.0+) - NoSQL database for efficient data handling.
- MongoDB Atlas (cloud-hosted) or local installation.
- MongoDB Compass: GUI for managing MongoDB collections and documents.

### Browsers:
- Google Chrome, Firefox, Edge, or Safari (latest versions for development and testing).

### Additional Tools:
- **Postman:** For API testing and endpoint validation.
- **MongoDB Compass:** Visual interface for database management.
- **ESLint:** Code linting and quality enforcement.

## 3. System Requirements

### Client-Side (End Users):
- **Browser:** Chrome 90+, Firefox 88+, Safari 14+, or Edge 90+ with JavaScript enabled.
- **Operating System:** Windows 7+, macOS 10.12+, Linux, Android 8.0+, or iOS 12+.
- **RAM:** 2 GB minimum.
- **Internet Connection:** Minimum 2 Mbps for real-time messaging.
- **Screen Resolution:** 320px width minimum; 1920x1080 recommended.

### Server-Side (Deployment):
- **Node.js Runtime:** v16 or higher.
- **Server RAM:** 512 MB minimum; 1 GB recommended.
- **Storage:** 10 GB SSD minimum.
- **Network:** Stable connection with 10 Mbps minimum speed.
- **Port:** Port 5001 (configurable) for backend server.
